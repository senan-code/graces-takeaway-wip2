# Grace's Takeaway, Piltown: website (design preview)

A fast, mobile-first static site for Grace's Takeaway, Main Street, Banagher, Piltown, Co. Kilkenny.
Plain HTML, CSS and a little JavaScript. No framework, nothing to install.

**Status: pitch preview.** The owner has not seen or approved this. Keep the
"Design preview" bar, the `noindex` tag and `robots.txt` until they do.

## Files

```
index.html           Home page (edit by hand): hero, menu highlights, order box, hours, find us
menu.html            GENERATED by tools/build.py. Do not edit by hand.
graces-preview.html  GENERATED single-file preview (home + menu, works offline). Do not edit by hand.
styles.css           All styling. Brand colours are variables at the top.
script.js            "Open now" badge and today's row in the hours table (Irish time)
assets/logo.png      Logo, cropped from a screenshot (top of the G is cut off; replace with the owner's file)
tools/build.py       Menu data (MENU) + builds the two generated files + checks the hours
robots.txt           Blocks search engines during the preview
vercel.json          Tells Vercel this is a plain static site (no build step)
```

## Common jobs

**Change a menu item or price:** edit `MENU` in `tools/build.py`, then run

```bash
python3 tools/build.py
```

**Change opening hours:** edit both places in `index.html` (the JSON-LD block in
`<head>` and the hours table, both marked `HOURS`), then run `python3 tools/build.py`.
The build stops with an error if the two disagree. The "Open now" badge reads the
JSON-LD, so there is nothing to change in `script.js`.

**Change the header or footer:** edit them in `index.html` and rebuild; `menu.html` copies them.

**View locally:** open `index.html` in a browser, or run `python3 -m http.server` and visit
http://localhost:8000.

## Placeholders to replace (search for these comments in `index.html`)

- `ORDER-LINK`: point the "Order online" button at the chosen ordering platform.
- `SHOPFRONT-PHOTO`: add the shopfront photo.
- `LOGO`: swap in a full-resolution logo.
- `PREVIEW`: remove the `noindex` tag (and relax `robots.txt`) at launch.
